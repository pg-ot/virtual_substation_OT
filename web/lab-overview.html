Checking capture agent…

    For a fresh MMS read of the trip in a disposable direct-HTTP project: establish CLOSED, GOOD and trip clear with 120 A renewing. With default 200 A pickup, select all lab networks for MMS, GOOSE and IEC 104, then start a 60-second capture. In the station page set the slider to 250 A and choose Apply slider value. Keep that page open and the input lease active; wait for 250 A, asserted trip and OPEN/GOOD. While holding 250 A and capture is running, have the instructor run the read-only command below on the Docker host. Afterwards apply 120 A and stop the capture. Do not use the automatic sequence: it returns to 120 A after three seconds. Do not restart a captured container.

    Inspect station-hmi / station for MMS, breaker / station for GOOSE and control-centre / supervisory for IEC 104. A single station interface may miss GOOSE and cannot establish supervisory-network coverage.

    The command appears when a capture includes the station-hmi station interface.

    For MMS in Wireshark, Decode As TPKT on TCP ports 8102–8104. A separate station-hmi read creates the association; it does not restart the HMI reader. Check the individual capture and manifest for errors and drops.

    Maximum 10,000 packets per interface. Capture adds load and may affect timing. Files can contain sensitive traffic and are retained on the host.
