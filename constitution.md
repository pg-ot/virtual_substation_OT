# Project principles

1. Process state, protection decisions and displayed telemetry have explicit owners.
2. A learner can distinguish a command acknowledgement from equipment feedback and stale information from live information.
3. All scenarios involve fictional equipment and run deterministically without access to utility infrastructure.
4. Each feature traces from acceptance criteria to tasks and executable checks. Update the spec and plan when behavior changes.
5. Record durable architecture decisions before making dependent changes. Supersede accepted decisions by linking a new ADR and updating the index.
6. Ship and build the simulator using open-source software and redistributable assets. Record upstream licenses and redistribution obligations when pinning dependencies.
