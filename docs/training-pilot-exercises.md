# F01 pilot exercise matrix

**Plant-MMS profile only.** The active direct-HTTP profile has different
current behavior and recovery steps. Use the
[direct-HTTP pilot guide](training-direct-http-pilot.md) instead of this
matrix for that profile.

Start with the instructor reset and verify CLOSED, approximately 118–122 A and a clear protection trip. The instructor console and its controls are described in [instructor scenarios](instructor-scenarios.md). All electrical values are generated by SIMF01.

| Exercise | Instructor setup | Trainee task | Expected result |
| --- | --- | --- | --- |
| Normal bay | Reset baseline | Compare plant, IED, HMI and control-centre indications. | Breaker CLOSED, approximately 118–122 A and trip clear. |
| Local station switching | Reset baseline | Open and close 52-F01 from its station faceplate. | OPEN corresponds to 0 A and CLOSED to approximately 118–122 A, with confirmed feedback. |
| Feeder fault | Apply fault from the closed baseline. | Inspect protection, GOOSE, breaker and supervisory indications. | PRF01 trip is asserted, BRF01 opens and current becomes 0 A. |
| Failed opening | Select stuck breaker, then apply fault. | Find the breaker operation-failure indication and compare HMI and remote view. | Position remains CLOSED and operation failure is asserted. |
| Lost IEC 104 path | Stop the IEC 104 gateway. | Inspect the IEC 104 control-centre point quality. | The master marks the position stale. |

After each exercise, use reset and wait for baseline verification before proceeding. Capture packets at the relevant network interface to associate the observed application behavior with the protocol exchange. The test and protocol evidence is summarized in [component test matrix](component-test-matrix.md).

Use the [trainee worksheet](training-pilot-worksheet.md) and [instructor answers](training-pilot-instructor-answers.md) for the exercises. A complete human-led instructor rehearsal and browser walkthrough remain required before a training release.
